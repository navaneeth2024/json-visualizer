# JSON Visualizer

A simple, modern web app to visualize, search, and sort JSON data in a table. Built with HTML, CSS (Tailwind), and JavaScript.

## Features
- Upload and view JSON files as tables
- Search, paginate, and sort columns
- Copy column data, download as CSV/JSON
- Dark mode and responsive design

## Getting Started
1. Clone this repository:
   ```sh
   git clone <your-repo-url>
   ```
2. Open the folder and launch `index.html` in your browser.

## Development
- All main code is in `index.html`, `styles.css`, and `script.js`.
- No build step required.
